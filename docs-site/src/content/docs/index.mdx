## Four rules it will not bend

These are the promises you can design around, not aspirations pencilled into a roadmap.

**It points; SuperPipeline holds.** SuperDispatch names a preferred agent, and SuperPipeline holds
the card for that agent for a short reservation that lapses on its own. SuperDispatch never claims
a card and never hands one over. (The maître d' does not carry plates. We checked. There's a test.)

**It reads, and never edits a roster.** It reads cards, rosters, load and history through each
product's public API and owns none of their data. When it spots a lane that rests on one agent, it
writes a [roster suggestion](/records/roster-suggestions/) for a person, and the person decides.

**Nothing requires it.** Switch it off and every agent claims by pull, exactly as before. When it is
slow or absent, the cost is the reservation window, never the claim.

**Every decision is a record.** You get the card, every candidate, each filter's result with its reason
code, the score that ranked the rest, the hold, and what became of the card. "Why did that go
there?" always has an answer. See [Decision records](/records/decisions/).
