## Four rules

<CardGrid>
  <Card title="It advises; SuperPipeline holds">
    SuperDispatch names a preferred agent. SuperPipeline holds the card for that agent for a short
    reservation that lapses on its own. SuperDispatch never claims a card or hands one over.
  </Card>
  <Card title="It reads, and never edits a roster">
    It reads cards, rosters, load and history through each product's public API and owns none of
    their data. Roster and supply changes it finds are advice for a person.
  </Card>
  <Card title="Nothing requires it">
    Without it, every agent claims by pull as before. When it is slow or absent the cost is the
    reservation window, never the claim.
  </Card>
  <Card title="Every decision is a record">
    The card, every candidate, each filter's result with its reason code, the score that ranked the
    rest, the hold, and what became of the card.
  </Card>
</CardGrid>
